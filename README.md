# fmic: Find Me In Crowd

An app that helps friends find each other in crowds, such as at concerts and festivals.
One phone is the Lighthouse; the others navigate back to it using GPS, Bluetooth signal
trend, and finally the Lighthouse's blinking screen colour.

- `prototype/`: two-phone Bluetooth and screen-blink prototype (React Native + Expo).
  See [prototype/README.md](prototype/README.md) for build and test steps.
